# UstaBIM Tools

Проект находится на архитектурном этапе. Общий контекст и границы системы описаны в `README.md` и каталоге `docs/`.

До отдельной задачи не создавайте приложения, бизнес-логику, миграции, workflow, авторизацию или CI/CD. Не добавляйте зависимости без явной необходимости.

Базовые проверки изменений:

```bash
find . -maxdepth 4 -type f | sort
docker compose config
git diff --check
```
