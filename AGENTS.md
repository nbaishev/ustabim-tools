# UstaBIM Tools

Проект содержит архитектурную документацию, запускаемый frontend-прототип и минимальные Supabase SDK-клиенты с health-check. Общий контекст и границы системы описаны в `README.md` и каталоге `docs/`.

До отдельной задачи не создавайте регистрацию, auth proxy, backend-бизнес-логику, миграции, workflow или CI/CD. Не используйте service role в браузере, не обходите RLS и сохраняйте честный статус UI-заглушек.

Базовые проверки изменений:

```bash
find . -maxdepth 4 -type f | sort
npm run lint
npm run typecheck
npm run test
npm run build
npm run test:e2e
docker compose config
git diff --check
```

## Формат итогового ответа

Каждый итоговый ответ после выполнения задачи обязательно должен завершаться разделами:

### Ручная проверка

Перечислить конкретные шаги, которые пользователь должен выполнить вручную. Для каждого шага указать ожидаемый результат. Если ручная проверка не требуется, написать: «Дополнительная ручная проверка не требуется».

### Следующая задача

Предложить только одну следующую небольшую, логически связанную задачу. Не начинать её реализацию без отдельного запроса пользователя.
